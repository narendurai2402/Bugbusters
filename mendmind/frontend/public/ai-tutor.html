Sure! Let's break down the Stack data structure in a clean, visual, and intuitive way.

1. What is a Stack?

A stack is a linear data structure that follows the LIFO (Last In, First Out) principle. This implies that the element inserted last is the very first one to be taken out.

🥞
Real-world Analogy: A stack of cafeteria trays or pancakes. You place new trays on the top, and whoever takes a tray removes the top one first!

2. Essential Stack Operations

push(val) → Inserts element to top O(1)
pop() → Removes top element O(1)
peek() / top() → Reads top without removing O(1)
isEmpty() → Returns true if stack empty O(1)

3. Python Implementation

Standard Array-based Stack
stack_demo.py 
class Stack:
    def __init__(self):
        self.items = []

    def push(self, item):
        self.items.append(item)  # O(1) amortized

    def pop(self):
        if not self.is_empty():
            return self.items.pop()
        raise IndexError("pop from empty stack")

    def peek(self):
        return self.items[-1] if not self.is_empty() else None

    def is_empty(self):
        return len(self.items) == 0
